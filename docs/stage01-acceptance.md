# Stage 01 验收

- SFTP 浏览连接复用，目录读取去掉前置 exists；SMB 复用会话并去掉目录 exists。
- 收藏目录不再是访问白名单；显示名称默认主机；路径可空；测试、保存、保存并浏览可分别操作。
- 真实 POSIX shell 与路径输入分开，cwd 同步、退出码保留、命令历史、停止命令、浮窗移动与缩放。

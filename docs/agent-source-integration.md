# 日志源码仓库与企业诊断集成

默认新工作区使用源码模式。源码入口复用当前日志格式及用户指定的源码文件列；行号只取源码行号，未知时为 0，不拿日志行号代替。最多取 64 个不同文件入口，按顺序找到首个有效索引匹配。

索引匹配向上查找最近的 Git 根（包含 worktree `.git` 文件），无 Git 时使用最具体的索引目录。同仓库文件合并；跨仓同名时用户选择一次。绑定和入口保存在日志历史 metadata，后续会话复用，不能用全局目录或另一条日志的仓库覆盖。源码缺失时给出明确提示，不自动切换为隔离模式；用户仍可显式选择隔离模式或已有隔离会话。

核心提示词始终通过 OpenCode `prompt_async.system` 注入，包括完整日志路径、仓库和索引入口。要求真实读取上下文、日志模板/错误码、调用链与触发条件，核对部署版本，区分首个异常与级联结果，结论按已定位、高可信待验证、证据不足分级。可选开关仅控制附加的详细 RCA 报告结构。源码锚点只是调查入口，不是已证实原因。

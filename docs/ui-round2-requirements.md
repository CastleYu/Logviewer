# LogViewer 第二轮 UI 需求（已确认实现）

> 同步自两轮已确认的 UI 需求与 StackTrace v3 设计定稿；保留 ACP（AI 工作区）与远程工作台全部现有能力，未确认模块保持现状。

---

## 一、全局与 Round 1 联动修订

- **G-1 自定义 Tooltip 与菜单层级（`Tooltip.tsx` / `Menu`）**：所有按钮、图标与图标化交互统一采用自定义 Portal Tooltip（400ms 延迟、自动避让视口边界、支持 `kbd` 快捷键角标及结构化内容），禁止依赖原生 `title=`；所有顶栏及工具栏下拉菜单通过 Portal 挂载至 `document.body`（`z-[320]`），解决 H10 等浮层遮挡与裁剪问题。
- **H3 位置调整（`AppHeader.tsx`）**：顶栏不再单独摆放「解析堆栈」开关，合并至顶栏「视图 ▾」菜单的「堆栈展示」分组内，并在菜单内补充 `Alt+S`「堆栈原文模式」切换及图例 Tooltip。
- **T1–T16 调查栏与辅助交互**：
  - 搜索（T1–T9）：单行「在当前筛选结果中搜索…」输入框 + 列选择器 + `.*` / `Aa` + 分组定宽 `[ ▲ | 搜索 / n/M | ▼ ]`，默认青绿色高亮（`emerald`）及 `#138a5a` 左侧高亮条，回绕底部/顶部轻量 Toast 提示。
  - 高亮（T 分裂按钮）：独立「高亮 ▾」菜单，支持切换预设颜色圆点、点击关键词回填搜索框、显隐眼睛切换、删除与清除全部。
  - 复制与导出（T14）：统一收敛至工具栏右侧「复制 / 导出 ▾」菜单，支持作用域切换（`选中` / `筛选` / `全部`）与 `✓ 已复制 N 条` 即时反馈。
  - 首列 `#` 行号跳转（T12，`LineJumpHeader.tsx`）：点击 `#` 或 `Ctrl+G` 按源行号跳转，不在当前筛选结果时给出明确 Toast 提示。
  - 浮动错误导航（T15/T16，`FloatingErrorNav.tsx`）：停靠表格右下角，支持按手柄在表格容器内拖拽与双击复位，位置持久化存储，支持 `F2` / `Shift+F2` 上下跳转。
  - 表头筛选区间扩展（T10/T11）：在 `ColumnFilterPopover` / `ConfiguredFieldFilterPopover` 底部整合可折叠「首个至末个匹配区间」筛选输入。

## 二、M3 首页 / 空状态（`DropZone.tsx`）

1. **三列等高面板布局**：宽屏下采用三列等高网格（`lg:grid-cols-3 lg:h-[500px]`），窄屏垂直堆叠。
2. **文件拖入高亮约束**：仅当拖拽载荷包含真实文件（`DataTransfer.types` 含 `'Files'`）时亮起拖拽放置框，忽略页面内文本或元素拖拽。
3. **左列（拖放与主入口）**：
   - 保留 `[远程服务器]` 与主按钮 `[选择文件]`，移除内置示例日志入口与未确认的「按路径打开」独立主按钮。
4. **中列（最近打开）**：
   - 自动过滤历史中的示例日志（`HistoryKind.Sample`），保留本地与远程历史，支持容器内纵向滚动查看全部记录。
   - 无真实打开记录时展示空状态文案：`还没有打开过日志`。
   - History 下拉菜单（H7）与历史弹窗（`HistoryBrowser.tsx`）保持一致的过滤与空态规则。
5. **右列（远程服务器）**：
   - 展示全部已注册服务器列表，支持按名称 / 主机 / 用户名 / 路径关键词实时搜索。
   - 头部显示服务器总数徽标与 `+ 注册` 快捷入口。
   - 列表项展示就绪状态点、服务器名称、`user@host:port` 地址以及 `SFTP` / `SMB` 协议标签，点击直达远程文件浏览器。

## 三、M10 底部固定选中操作栏（`SelectionActionBar.tsx`）

1. **常驻形态**：只要已打开日志文件，底部固定展示 `32px` 高度（`h-8`）状态与选中栏，不再仅在选中行后才出现。
2. **左侧区域**：
   - 提供「全选筛选结果 M 条」按钮（全选态高亮显示）。
   - 显示当前选中计数：`已选 N 条` 搭配可点击 `Esc 清空` 徽标，未选行时显示 `未选择`。
   - 全局 `Esc` 清空当前选中行，但在输入框等可编辑元素内或菜单（`[data-menu]`）/ 对话框（`[role="dialog"]`）打开时自动忽略。
3. **右侧区域**：固定显示当前统计 `显示 M / K 条`（当前筛选数 / 总记录数）。
4. **职责收口**：导出、复制与行 INSPECT 面板不再占用底栏空间，保持低视觉干扰。

## 四、M8 / M9 v3 内联堆栈展示（`InlineStackTrace.tsx` / `stackClassify.ts`）

> 放弃右侧独立 `LogInspector` 面板及旧版堆栈弹窗，堆栈直接在日志表格正文下方行内展开；`StackCell` 仅保留行号区间徽标，不触发弹窗。

1. **适用范围**：同时接入内置日志表格（`VirtualLogTable`）与自定义配置表格（`ConfigurableLogTable`），行内增减高度自动通过虚拟列表重新测量并留出底部滚动余量。
2. **异常链分区与整行标题点击**：
   - 自动切分 Python 异常链（`During handling of...` / `The above exception...`）与 Java 异常链（`Caused by:`），每段独立为带边框卡片容器（`.area`）：最终异常呈红色语义（`Exc` + `border-danger/35`），成因异常呈橙色语义（`Cause` + `border-warn/35`）；Python 分隔说明句作为连接标签渲染于卡片之间。
   - 整个异常卡片标题栏为全宽可点击按钮，支持整行点击展开或折叠该段堆栈，右上角显示该段栈帧数量。
   - **默认展开与会话记忆**：默认展开全部异常区段，手动展开/折叠状态在会话内存 `Set` 中保持，避免虚拟滚动复用行导致状态丢失。
3. **三列行内结构与左侧快捷操作**：
   - 每行采用 `44px` 操作槽 + `16px` 语义标记 + 等宽源码/帧内容的三列网格。
   - 左侧悬停（焦点行常显）提供两个动作按钮：
     - **复制定位**（`path:line`，点击后展示 `1.4s` 绿色 ✓ 反馈）。
     - **打开源码**：非依赖帧且存在文件路径时可用，直接复用顶部 H5 打开程序切换器与 `SourceApi` 跳转至 IDE（多匹配时弹出消歧菜单）。
4. **栈帧分类与依赖折叠**：
   - 5 步源码归属分类器：显式依赖规则/默认黑名单 > `SourceSettings` 按格式自定义「业务包/路径前缀」与「依赖包/路径前缀」> 日志关联源码目录/仓库名 > 全局标准库与三方路径模式。
   - 焦点帧自动高亮：Python 优先最后一条 `App` 业务帧，Java 优先第一条 `App` 业务帧标记为 `Focus` 焦点帧；其余业务帧标记为 `App`。
   - 连续 `>= 2` 条 `Lib` 依赖帧分组**默认全部展开**，点击分组条可收起为 `… N 个依赖帧（点击展开）` 或再次展开，永不折叠 `Focus` 或 `App` 帧。
5. **视图开关与 `Alt+S` 原文切换**：
   - 顶栏「视图 ▾」菜单内提供「解析堆栈」（状态持久化，附带悬停图例）与「堆栈原文模式」（全局快捷键 `Alt+S` 切换，原文模式支持一键复制完整原始堆栈）。

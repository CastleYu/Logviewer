## 0. 全局要求

### G-1 悬停提示组件化
- 所有按钮、图标按钮、徽标的悬停提示统一使用自定义 `Tooltip` 组件，不再使用浏览器原生 `title`。
- 样式与 `lv-menu` 一致：`surface` 背景、`line` 边框、圆角 6px、阴影 `--shadow-window`、字号 11px；深浅主题自动适配。
- 内容格式：`说明` 一行，快捷键用 `lv-kbd` 样式放在右侧。
- 出现延迟 400ms，移开立即消失；自动避让视口边缘；层级高于顶栏和所有下拉菜单。
- 仍保留 `aria-label`，保证无障碍。

**验收**
- [ ] 全局搜索 `title=` 只剩非交互元素（或 0 处）；按钮全部改用 `Tooltip`。
- [ ] 深色、浅色下截图，提示样式与下拉菜单一致。
- [ ] 视口最右侧按钮的提示不溢出屏幕。
- [ ] 提示不被顶栏、调查栏或下拉菜单遮挡。

### G-2 常量
- 新增的模式、菜单 id、localStorage 键、颜色 token 全部放在常量文件中，不写字符串字面量。

**验收**
- [ ] 新增和修改的代码中没有魔法字符串键。

## 2. 调查栏 T

### T1–T9 搜索与高亮重构

#### 布局
```
[ 全部列 ▾ | 输入框 ............ × .* Aa ]  [ ▲ 搜索 ▼ ]  [ 🖍 高亮 ▾ ]
```
- 去掉「定位 / 高亮」模式切换（T1、T2 删除），只有一个输入框。
- 「定位」统一改名为「**搜索**」。
- 「高亮」是输入框右侧的独立操作按钮，不是模式。
- ▲▼ 使用项目当前的上下箭头图标（`ChevronUp` / `ChevronDown`）。

#### 搜索按钮组 `[ ▲ 搜索 ▼ ]`
- **初始状态**：显示 `▲ 搜索 ▼`。
- **已搜索后**：中间文字变成序号 `12/345`；没有匹配时显示 `0/0`，文字为危险色。
- 点击 ▲ 或 ▼ 本身就会执行搜索（效果等同于点「搜索」），不需要先点搜索。
- **搜索起点**：以当前屏幕可见区域的第一行（光标头部）为起点：
  - ▼：从可见区域首行之后找下一条匹配；
  - ▲：从可见区域首行之前找上一条匹配；
  - 到头后循环，并在提示中显示「已从头开始」。
- 输入框内按 Enter = ▼，Shift+Enter = ▲。
- 关键词或范围改变后，序号重置为初始状态。
- T3 搜索列、T5 正则、T6 大小写保留在输入框内，作用于搜索和高亮两种操作。

#### 高亮按钮 `[ 🖍 高亮 ▾ ]`
- 左半「高亮」：把输入框当前内容加入高亮列表（带当前正则、大小写设置），自动分配颜色。空内容、重复内容、无效正则时禁用，并在提示中说明原因。
- 右半 `▾`：下拉列表，样式与「打开 ▾」一致，展示已高亮的条目：
  - 每行：色点（点击换色）、关键词、`.*` / `Aa` 标记、显示/隐藏开关、删除 `×`；
  - 点击关键词把它填回输入框；
  - 底部「清除全部」。
- 已有高亮时按钮上显示数量，例如 `高亮 3`。

#### 高亮颜色
- **浅色模式下，当前搜索命中和高亮的默认色改为绿色**（`#c8f0d8` 底、`#0f6b43` 字；当前命中行加 `#138a5a` 左边框）。
- 高亮列表的第一个预设色改为绿色，其余预设顺序后移。

**验收**
- [ ] 页面上没有「定位」「模式切换」字样，只有「搜索」。
- [ ] 初始显示 `▲ 搜索 ▼`；输入关键词后点 ▼，中间变为 `n/总数`。
- [ ] 把表格滚到中间（例如第 5000 行附近）后点 ▼，跳到的是该位置之后的第一条匹配，而不是全文第一条。
- [ ] 同样位置点 ▲，跳到该位置之前最近的一条。
- [ ] 在最后一条点 ▼，回到第一条并提示「已从头开始」。
- [ ] 无匹配时显示红色 `0/0`。
- [ ] 输入内容后点「高亮」，表格中出现绿色高亮，按钮显示 `高亮 1`。
- [ ] 打开高亮下拉，可以改颜色、隐藏、删除、清除全部。
- [ ] 下拉不被任何栏遮挡。
- [ ] 浅色模式截图：高亮和当前命中都是绿色。

### T14 复制 / 导出
**现状核实**：与底部选择栏**部分重复**——调查栏导出的是「当前筛选结果」，底部选择栏导出的是「选中行」，两者菜单项相同，只是范围不同，用户无法区分。

**需求**
1. 只保留调查栏一个「复制 / 导出 ▾」入口；底部选择栏去掉导出菜单，只保留「已选 N 条」、AI 分析、全选、清除。
2. 下拉菜单顶部有范围选择：
   - `选中的 N 条`（有选中时默认）
   - `当前筛选结果 M 条`（无选中时默认）
   - `全部 K 条`（筛选后 M < K 时出现）
3. 按钮和每个菜单项的悬停提示写明将要操作的范围和条数，例如「复制当前筛选结果 1,234 条的原文」。
4. 完成后在按钮原位显示「✓ 已复制 12 条」1.6 秒。

**验收**
- [ ] 底部选择栏没有复制 / 导出菜单。
- [ ] 不选行时打开菜单，默认范围是「当前筛选结果」；选中 3 行后打开，默认范围是「选中的 3 条」。
- [ ] 三种范围分别导出 CSV，行数与范围一致。
- [ ] 每个菜单项的悬停提示带范围和条数。

### T15 / T16 错误导航 —— 改回浮动组件
**需求**
1. 从调查栏移出，恢复为浮动在表格右下角的组件（参考原版样式，但收敛尺寸：高 40px 左右，不用大号图标和脉冲动画）。
2. 内容：`⚠ 3/2,622 错误  ▲ ▼`；无错误时置灰显示「无错误」。
3. **支持拖动**：按住组件左侧的拖动柄移动；位置限制在表格区域内；位置记到 localStorage，刷新后保持；双击拖动柄恢复默认位置。
4. 不遮挡表格滚动条和底部选择栏；检查器打开时自动避让到检查器左侧。
5. F2 / Shift+F2 快捷键保留，写在悬停提示中。

**验收**
- [ ] 调查栏中没有错误导航。
- [ ] 表格右下角出现浮动组件，▲▼ 和 F2 能在错误行间跳转。
- [ ] 拖到左上角后刷新，位置保持；双击拖动柄回到默认位置。
- [ ] 拖不出表格区域。
- [ ] 选中行出现底部选择栏或打开检查器时，组件不遮挡它们。
